#Car Rental CRUD Management System (Python)

*Overview*
A simple Car Rental Management System built using Python.This project 
demonstrates basic CRUD operations:
  - Create (Add a new car)
  - Read (View all cars)
  - Update (Edit car details)
  - Delete (Remove a car)
*Features*
  - Add new cars with ID, brand, model, and price
  - View all available cars
  - Update car information (price/model)
  - Delete a car by ID
  - Fully menu-driven program
  - Simple and clear code for beginners
*Technologies Used*
   - Python 3
   - File Handling (JSON)
   - Console-based menu system
